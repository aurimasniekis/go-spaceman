# Project status

SpaceMan is built in five milestones of working vertical slices. **Milestone 1** (foundation and the first runs) is
nearly complete: central, nodes, spaces, runs, leases, recordings, access control and the web UI described in these
guides. Everything else in the product contract is planned and not yet usable.

Each requirement below is listed with its state and evidence. **Simulated** evidence comes from automated tests with
fakes or embedded dependencies; **real** evidence comes from tests against the real dependency (named, with the date).
A requirement without real evidence has not been verified against the real system yet.
