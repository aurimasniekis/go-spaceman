# The sidebar and settings hubs

The sidebar is short: it holds the pages used every day, and three hubs for the settings pages. Each page keeps its own
address, so every existing link and bookmark still opens it.

## The sidebar

- **Work**: Overview, Needs you (with the number of pending human actions), Terminals, Spaces and
  [Usage](/guide/usage-page).
- **Configuration**, **Integrations** and **Access**: one entry each, which opens the hub's first tab you may see.

[Attention](/guide/attention) is not in the sidebar; it is reached from the [Overview](/guide/overview). Your account is
in the user menu.

## The hubs

| Hub | Tabs |
|---|---|
| **Configuration** | Prompts, Roles & profiles, Skills, Approval policies, Action types, Cross-space, Nodes |
| **Integrations** | Events, MCP servers, Accounts, Git SSH keys, Harbor Pilot |
| **Access** | Users, Sign-in providers, API tokens, Audit log, Backups, System |

Each settings page shows its hub's tabs under its heading as plain links, so you can middle-click one into a new tab.
The current tab is marked as the current page for assistive technology.

## Who sees a hub

A hub appears in the sidebar only if you can see at least one of its tabs, and a tab appears only if you may read its
page. Administrators see every hub and tab. A user with space grants sees Events and API tokens, and no Configuration.
The hub entries are `/configuration`, `/integrations` and `/access`; each opens the first tab you may see.
